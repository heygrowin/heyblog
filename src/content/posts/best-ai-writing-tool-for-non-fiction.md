### How to catch hallucinated facts

1. **Enable source display** – wherever a tool can show URLs or footnotes, set the default to “always show sources”.  
2. **Cross‑verify with trusted databases** such as Google Scholar, PubMed, or official statistics portals.  
3. **Use a second AI as a reviewer** – for example, ask Claude to “review the facts in this paragraph and list any that lack a source”.  
4. **Maintain a manual reference log** in a reference‑manager (Zotero, Mendeley, EndNote). Any claim without a linked entry should be treated as unverified.

### Practical genre‑specific guidance

- **Journalism:** Start with a system prompt that includes “Write in Associated Press style” and enable browsing to pull the latest public records. After the draft, run the “Fact‑check” command and replace any AI‑generated citations with the URLs provided by the browse add‑on.
- **Academic:** Use the “Cite” button to generate a bibliography in the required style, then export to a `.bib` file if you are writing in LaTeX. Verify each DOI or URL manually; the model does not guarantee that every reference exists.
- **Memoir:** Provide a detailed voice description (e.g., “first‑person, reflective, with occasional humor”) in the system message and use the “Regenerate” function to iterate on sections that feel generic. Manual editing remains essential for authenticity.
