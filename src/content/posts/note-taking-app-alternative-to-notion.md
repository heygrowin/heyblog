## 1. Top Notion‑style note‑taking apps – quick‑hit pros & cons  

| App | Core strength | Biggest drawback vs. Notion |
|-----|---------------|-----------------------------|
| **Obsidian** | Markdown‑based vault with graph view and a large plug‑in ecosystem; files are stored locally. | No built‑in real‑time collaboration; sharing requires a third‑party service or Obsidian Sync. |
| **Craft** | Polished native macOS client and web‑based editor; real‑time sharing works without extra setup. | Windows is only available through a browser; relational tables are limited to simple grids. |
| **Coda** | Spreadsheet‑style docs with formulas, packs and automation; works well for workflow‑heavy teams. | Costs rise noticeably when moving from the Pro plan to Enterprise or when adding many seats. |
| **Roam Research** | Core bi‑directional linking and daily‑note workflow that encourages networked thinking. | No fully offline desktop client as of mid‑2024; the mobile apps provide only limited offline caching. |
| **Logseq** | Open‑source, local‑first design; markdown‑native with an optional encrypted sync service. | Interface is functional but less polished; advanced queries have a learning curve. |
| **ClickUp Docs** | Docs are tightly integrated with task management, time‑tracking and agile boards. | The all‑in‑one approach can feel cluttered when the primary need is pure note‑taking. |
| **Microsoft OneNote** | Free, deep integration with the Microsoft 365 ecosystem and strong handwriting support. | Lacks relational databases and hierarchical page structures that Notion provides out of the box. |

### Decision matrix – which app fits common scenarios?  

- **Solo researcher or writer who wants full offline control** – Logseq (free) or Obsidian + optional Sync ($8 / mo) are the lowest‑cost routes.  
- **Small team (2‑5 people) that needs real‑time collaboration and a polished UI** – Craft Pro ($10 / mo per user) offers native macOS editing and web access for Windows.  
- **Medium‑size team (5‑20 people) that runs workflow automations** – Coda Pro ($10 / mo) provides formulas and packs; consider Enterprise ($30 / mo) if SSO or dedicated support is required.  
- **Network‑thinking enthusiasts who value bi‑directional linking above all** – Roam Research (individual $15 / mo) is purpose‑built, though it lacks offline desktop support.  
- **Teams that already use task‑oriented platforms** – ClickUp Docs ($5 / mo per user) integrates notes with tasks and agile boards.  
- **Users already in the Microsoft ecosystem** – OneNote is free and works well for handwritten notes; upgrade to Microsoft 365 only if you need the larger Office suite.
