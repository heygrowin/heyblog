## 1. Free PDF editors that can replace Adobe for basic text, image, and page work  

| Tool | One‑sentence pros | One‑sentence cons |
|------|-------------------|-------------------|
| **LibreOffice Draw** | Full‑featured open‑source editor that handles text, images and page layout without watermarks. | The interface resembles a drawing program; large files may load slowly. |
| **PDF‑XChange Editor (Free)** | Fast Windows viewer with rich annotation tools and limited text editing. | Advanced functions such as image replacement require the paid version; some premium tools add a “Created with PDF‑XChange Editor” label. |
| **Foxit Reader (Free)** | Light‑weight viewer that supports annotation, form filling and minor text edits; runs on Windows, macOS and Linux (via Wine). | Real page‑level editing (moving or deleting pages) is locked behind a license; occasional product ads appear. |
| **Sejda PDF (Online & Desktop)** | Both versions let you edit text, images and pages without watermarks up to 200 pages per task. | Free online use caps each task at 50 MB or 200 pages; the desktop free version shows a “powered by Sejda” banner on the start screen. |
| **PDFsam Basic** | Open‑source tool that splits, merges, rotates and rearranges pages; completely watermark‑free. | It cannot edit the actual content of a page (text or images). |
| **Smallpdf (Online)** | Drag‑and‑drop UI for basic editing, form filling and format conversion; works in any browser. | Free tier limits you to two tasks per hour and files under 5 MB; processing occurs on Smallpdf’s servers, which may raise privacy concerns. |
| **LibrePDF (LibrePDF‑iText)** | Java‑based library with a thin GUI that can edit text and images; fully open source. | Requires a Java runtime; the UI is minimal and may feel technical for casual users. |

**Recommendation** – For a desktop solution that covers most everyday editing (text, images, page rearrangement) without watermarks, **LibreOffice Draw** offers the most complete free feature set on Windows, macOS and Linux. Pair it with **PDFsam Basic** when you need heavy page‑reordering; together they provide a workflow comparable to Adobe Acrobat’s core capabilities while remaining open source.

## 3. Safety and privacy: are the free options trustworthy?  

| Tool | Open‑source? | Data‑handling model | Known security incidents | Hidden fees / trial locks |
|------|--------------|---------------------|--------------------------|---------------------------|
| LibreOffice Draw | Yes (Apache License) | All files remain on the user’s device; no telemetry by default. | No major public incidents. | None – completely free. |
| PDF‑XChange Editor | No (proprietary) | Optional telemetry; can be disabled in **Preferences → General → Enable usage data collection**. | Past vulnerability (CVE‑2022‑XXXX) patched; updates released regularly. | Free version adds a “Created with PDF‑XChange Editor” label only when premium tools are used; otherwise no paywall. |
| Foxit Reader | No (proprietary) | Sends optional usage statistics; can be turned off during installation. | Minor vulnerability disclosed in 2021, patched quickly. | No hidden fees; advanced editing requires purchase. |
| Sejda PDF | No (proprietary SaaS) | Files uploaded to encrypted servers, auto‑deleted after a few hours. | No public breach reports. | Free tier limited by task count and page/size caps; no hidden charges. |
| PDFsam Basic | Yes (GPL) | Local processing only; no network activity. | No known incidents. | Fully free, no hidden fees. |
| Smallpdf | No (proprietary SaaS) | Files stored temporarily on EU/US servers, deleted after 1 hour; policy states no reuse. | No reported breaches. | Free tier limited to two tasks per hour; no hidden fees. |
| LibrePDF | Yes (LGPL) | Local Java process; no telemetry. | No known incidents. | Free, no hidden fees. |

**Takeaway** – Open‑source tools (LibreOffice Draw, PDFsam Basic, LibrePDF) keep documents on your computer and provide the highest assurance that data never leave the device. SaaS editors (Sejda, Smallpdf) are convenient but require trust in their server‑side handling; both publish clear retention policies. Proprietary desktop apps (PDF‑XChange, Foxit) are widely used and receive regular security updates, but they collect optional usage data unless you disable it during setup.
