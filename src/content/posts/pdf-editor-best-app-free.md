## Recommendation  

If you need a PDF editor that works entirely offline, adds no watermarks, and is available at no cost on the three major desktop operating systems, **LibreOffice Draw** is the most straightforward option. LibreOffice Draw is part of the LibreOffice suite, released under the LGPL v3 and MPL v2.0 licences, and provides native installers for Windows 10 (1809) or later, macOS 12 (Monterey) or later, and the current releases of major Linux distributions such as Ubuntu 20.04 LTS, Fedora 33, and Debian 11. The application supports annotation, basic text editing, page rearrangement, and PDF merging/splitting without any usage caps. Its main limitation is a drawing‑oriented text‑editing interface and the absence of built‑in OCR; a separate OCR tool is required for scanned documents.

For users who prefer a Windows‑only solution with a richer set of annotation tools and optional OCR, **PDF‑XChange Editor** offers a free version that runs locally. The free build adds a small “PDF‑XChange” banner only when a premium‑only feature is used, as documented in the product’s feature matrix [¹].  

Below is a ranked list of six free PDF editors that can be used without a subscription, followed by detailed comparisons of features, limits, platform support, and privacy practices.

### Getting started with the top recommendation – LibreOffice Draw  

1. Visit the official download page: <https://www.libreoffice.org/download/download/>.  
2. Choose the installer that matches your operating system (Windows 10 or later, macOS 12 or later, or a supported Linux distribution) and run it.  
3. Launch LibreOffice and select **Draw** from the start screen, or open a PDF file directly; LibreOffice will open it in Draw automatically.  
4. Use the **Text** tool (the “T” icon) to add new text boxes. Existing text can be edited by double‑clicking the box; you may need to adjust surrounding objects manually.  
5. Add annotations with the **Comment** or **Shape** tools on the right‑hand toolbar.  
6. To rearrange pages, open the **Navigator** (F5), drag pages between documents, or use **File → Export As → PDF** after rearranging.  
7. Save the edited file with **File → Export As → Export as PDF**; no watermarks are added.
